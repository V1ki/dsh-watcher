# 04 · 性格衣柜与查资料

> 性格衣柜怎么学你说话、认图记人，以及统一资料库怎么按圈层安全翻查跨平台历史。

想让助理既像你本人一样自然接话，又能随时帮你翻出几个月前的聊天或项目记录，全靠「性格衣柜」和「统一资料库」这两座宝库。

---

## 一、性格衣柜：一人千面不串戏

所有说话风格、人设卡片和记忆本，都统一收在侧边栏的 **「性格衣柜」** 里。微信连接器和 GitHub 连接器不再各自维护一套设定，而是直接去衣柜里挑一张挂上。

| 房间场景 | 挂哪张卡片 | 这个房间记什么偏好 | 绝不会串什么 |
|---|---|---|---|
| 家人群 | 轻松口语卡 | 家人爱看简短暖心回复，不爱听长篇说教 | 不带工作术语和代码细节 |
| 项目群 | 干练助理卡 | 同事喜欢先给结论、再列三条要点 | 不带家里照片和私事 |
| 开源仓库 | 严谨审查员卡 | 维护者习惯先看复现步骤和最小改动 | 不带任何微信聊天记录 |

围绕这套衣柜，日常有四项很实用的本事：

- **从你的旧话里学口吻**：选一批你平时发过的聊天样本，衣柜会提炼出你的句长、习惯用词和说话语气，保存成一份精简画像。以后聊天只带画像，不每次塞一大堆原文。
- **按房间慢慢记住偏好**：聊着聊着，如果某个群或仓库明确表达过喜好，衣柜会把这条偏好连同原话依据单独记在这个房间名下。每个房间最多留 24 条、每次带最近 16 条，随时可改、可撤回、可清空；朋友圈和试聊窗口绝不自动乱记。
- **收好你的长期背景文档**：你可以把个人背景资料导入衣柜，在专属私聊时按内容相关度自动翻出来参考。这份资料严格归你本人私用，绝不带进任何群聊或外部任务。
- **先试聊再正式上岗**：改完人设拿不准语气时，直接在衣柜里和它试聊几句听听感觉，满意了再挂到正式房间。试聊不会往外发真消息，也不会弄脏记忆本。

### 三步给房间配好第一张性格卡

1. 打开侧边栏的 **「性格衣柜」**，新建一张性格卡，写清说话语气和忌讳。
2. 喂一批你平时发过的聊天样本让它提炼口吻，顺手在试聊区聊两句听听感觉。
3. 切到「微信消息」或「GitHub」面板，在对应群或仓库下选定这张卡；日后想调语气，点一键跳转按钮就能回到衣柜统一改。

## 二、发图发视频怎么「认得人」

亲友群里少不了晒娃、晒宠物、发聚会照片和短视频。如果 AI 每次都像陌生人一样问「这是谁呀」，聊天就会很生硬。性格衣柜为此准备了一套有分寸的认图记人本事。

日常用起来通常分三步走：

1. **提前建好参考卡**：把亲友群里常出现的人物、宠物或熟悉场景整理成参考卡片，再配上已经确认过的生活事件记录。
2. **收到新图自然对照**：下次群里发来新照片或短视频，AI 结合参考卡和事件记录认出熟人，自然接一句贴合语境的话。
3. **拿不准先留观察草稿**：如果画面里出现新线索但把握不够，系统只会生成一条待确认的观察草稿等你审核，绝不凭几帧画面擅自编造「这是谁送的礼物」之类没说过的话。

看一眼「认得准」和「拿不准」时的说话差别：

```text
把握很足时（参考卡匹配清晰）：
→ 「家里那只橘猫又霸占阳台晒太阳了，睡得真香。」

拿不准时（画面模糊或陌生面孔）：
→ 「这只小猫毛色真好看。」
   同时只在后台留一条待确认观察草稿，绝不硬猜名字或编造来历。
```

更重要的是，这套认图记忆**严格按圈层分开存放**：家人的照片和生活卡片只留在亲友圈里用，绝不会带到工作群；外部群或还没打圈层标签的群，回复时默认不附带任何内部参考图。

## 三、统一资料库：一个入口翻全平台历史

以前找一句话，得分别去翻微信聊天、翻 NAS 备份、翻 GitHub 评论和便签本。现在总控台把各处的只读历史接成了一座 **「统一资料库」**，AI 用同一个查档入口就能跨平台翻查：

| 资料来源 | 能查到什么 | 常见用法 |
|---|---|---|
| 近期微信记录 | 本地保留的近期群聊与私聊消息 | 查昨天项目群里定了什么时间 |
| 远端 NAS 聊天档案 | 长周期完整归档的微信历史记录 | 翻半年前某次讨论或按日期回看某群 |
| GitHub 讨论动态 | 盯防仓库里的 Issue、PR 与评论 | 查某个老问题当初为什么那样改 |
| 待惦记便签 | 正在惦记中或近期触发过的提醒 | 确认某件待办是不是已经记过便签 |
| 性格衣柜卡片 | 当前圈层允许查看的参考卡与事件 | 核对已确认的人物背景或事件时间 |

平时翻历史主要有两种顺手问法，不需要死记任何语法：

```text
问法一（搜关键词）：上个月项目群里提到「接口限流」那段怎么说的？
→ 统一资料库搜出原话片段，再顺手展开前后几句完整对话，免得断章取义。

问法二（不输关键词，按时间倒序翻）：帮我倒着翻一下项目群最近两天都聊了什么。
→ 只按群名和日期范围就能从新到旧列出近期聊天，不用硬凑关键词。
```

查 NAS 档案时还有一条防串群底线：**如果你提到的群名在档案里对不上号，系统会直接返回空结果，绝不会随便抓另一个群的记录来凑数。**

## 四、查资料看谁在问（圈层上限一览）

统一资料库不是谁来问都全盘托出。系统把所有记录分成 **公开外人、工作同事、亲友家人、私人专属** 四档，每次查档前都会先核对来问的人是什么身份，再按上限放行：

| 谁在问 | 默认能看到的资料档位 | 日常表现 |
|---|---|---|
| 你的专属私聊与本地控制台 | 全部四档（公开、工作、亲友、私人） | 你本人直接指挥，所有档案都能查 |
| 工作任务与私有仓库专人 | 公开 + 工作两档 | 能看项目资料，碰不到家人和私人记录 |
| 外部仓库与陌生来信专人 | 仅公开一档 | 只看公开信息，内部资料完全看不见 |
| 普通微信群聊（默认状态） | 不开放跨群查档 | 只聊本群内容，除非你本人 `@` 它临时单轮放行 |

还有一条省心的默认底线：**凡是还没打圈层标签的微信聊天、NAS 档案和便签，一律默认归入最高的「私人专属」档**。宁可多拦一步，也绝不会因为忘了贴标签就把私事漏给外人看。

如果后台任务查过内部资料怎么自动贴上「防泄密封条」、以及整套系统的四道安全防线，请看 [06-安全防线与隐私边界](./06-安全防线与隐私边界.md)。

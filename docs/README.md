## 按常见疑问直达

- **刚接触这套系统**：先看 [01-整体长什么样](./01-整体长什么样.md)，五分钟摸清六个模块和房间心智模型。
- **平时在微信里用**：重点看 [03-微信上怎么指挥它](./03-微信上怎么指挥它.md) 和 [04-性格衣柜与查资料](./04-性格衣柜与查资料.md)。
- **担心隐私或误发**：直接看 [06-安全防线与隐私边界](./06-安全防线与隐私边界.md) 和 [07-消息怎么发出去](./07-消息怎么发出去.md)。

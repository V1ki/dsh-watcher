# 03 · 微信上怎么指挥它

> 在微信里直接当老板：私聊助理、按作息收提醒、发口令调度任务，还能在群里临时跨群查档。

你不需要天天开着网页后台才能管它。出门在外或者靠在沙发上，打开微信就能像吩咐真人助理一样聊天、批草稿、派任务、翻历史。

---

## 一、你的专属私聊助理

当你用自己的微信号直接给机器人发私聊时，它进入的就是你的**专属老板频道**，和你在微信群里看到的表现完全不同：

- **默认说人话、直奔主题**：私聊里不套任何群聊分身人设，不装腔作势，问什么答什么，干脆利落。
- **长期记住上下文**：这是一间一直为你留着的专属房间，之前聊过的事、定过的偏好都连贯保留；初次启用时还会自动衔接最近一段私聊记录，不用从头铺垫。
- **连发几句自动合并**：微信里习惯把一句话拆成两三条连着发也没关系，系统会稍等片刻把连续消息拼成完整意思，再让助理统一回答，不会答非所问。
- **日常聊天和后台任务互不抢跑**：无论刚弹出过多少条任务通知，你在私聊里随口发话永远默认先和助理聊；只有明确引用某张通知卡片或点名任务编号时，指示才会转给对应的后台专人。
- **图片、语音、文章照样能接**：私聊里随手发张报错截图、一段语音或一篇公众号链接，助理看完内容就能直接帮你分析处理。

下面这个小例子，就是私聊助理平时接话的样子：

```text
你：刚才推的那条 12 号 Issue，草稿大概写了什么？
助理：专人排查出是暗黑模式样式遮挡了按钮，草稿里先向作者确认复现版本，并附了临时绕过办法。要我把完整草稿发给你看吗？
你：发吧，另外帮我翻下昨天项目群里定的发版时间。
助理：好，昨天项目群小王说定在本周五下午四点。
```

微信私聊和网页端「Router」面板看到的是同一批任务与提醒。在手机上批到一半，回到电脑前打开网页接着看完全同步。

## 二、按作息和你在不在电脑前发通知

后台任务有了进展、或者新来了值得你过目的动态，系统不会不分青红皂白狂发微信，而是结合当前作息和你是不是正盯着网页端来挑渠道：

| 当前场景 | 提醒怎么送达 | 体验感受 |
|---|---|---|
| 上班时段，正开着网页端 | 优先留在网页端面板 | 不拿微信打断你专注敲字 |
| 上班时段，离开电脑一阵子 | 自动兜底转到微信私聊 | 出门倒水开会也不漏重要事 |
| 下班时段 | 直接发到你的微信私聊 | 手机看一眼就能顺手处理 |
| 周末时段 | 非紧急提醒先攒进队列 | 周末图清净，有空再一起看 |
| 标为紧急的事项 | 任何时段立刻送达 | 真正火烧眉毛的事绝不耽误 |

### 攒多了自动合并成一张清爽卡片

短时间内如果积攒了三条及以上待发微信提醒，系统不会叮咚连发轰炸你，而是自动打包成一张清爽汇总卡片：

```text
有 3 条新动态等你过目：
1. [#a3f1] 示例仓库 12 号 Issue：已定位原因并起草回复草稿
2. [#b204] 示例仓库 18 号 PR：同事留了两条行内评审意见
3. [#c819] 便签提醒：明早例会前记得核对发布清单

直接回复「#编号 指令」可指挥对应任务，或直接和我聊。
```

每给你推完一条提醒或汇总卡片，系统还会悄悄往你的私聊助理里留一句简短回执。你回头随口问「刚才推的那条 12 号 Issue 怎么回事」，助理立刻就能接上话。

如果你觉得某段作息太打扰或太安静，随时可以在网页端「Router」面板里调整时段，还能先用「情境预演」试看效果。

## 三、在微信里精准派活（常用口令表）

在你的私聊窗口里，下面这些常用口令会由系统直接识别并分流，反应极快，不用让大模型反复猜你的意图：

| 你在微信里怎么发 | 系统会怎么处理 |
|---|---|
| 直接发文字、语音、图片或文章 | 和专属助理正常聊天、问近况、查历史记录 |
| 长按引用某条通知卡片直接回复 | 把你的意见精准转给这张卡片对应的后台专人 |
| `#编号 指令`（如 `#a3f1 先改措辞再发`） | 点名指挥指定编号的任务，需要时为这一轮临时放行资料权限 |
| `列表` / `还有啥` / `在忙啥` / `任务` | 立刻列出眼下所有待处理和进行中的任务编号 |
| `批准` / `算了` | 配合编号或引用草稿提醒，拍板放行或作废待发草稿 |
| `确认 8位码` / `拒绝 8位码` | 单次放行或拦下正在等你点头的高危操作 |
| `批准本轮任务 8位码` | 放行本次高危操作，并允许这轮任务同类步骤不再反复打扰 |

### 两个最顺手的微信指挥小场景

- **一边走路一边改草稿**：看到汇总卡片里的 `#a3f1` 草稿语气太生硬，直接发一句 `#a3f1 语气柔和点，先别提下个版本计划`。后台专人改好重新放进草稿箱后，你回一句批准就发出去。
- **远程放行高危动作**：助理排查问题时需要执行高风险操作，微信立刻弹出一条带 8 位确认码的提示。你核对无误后回 `确认 3f9a2c10` 就单次放行；如果接下来还有几步同类操作，回 `批准本轮任务 3f9a2c10` 就能省去反复确认。

关于哪几类高危动作会弹出 8 位确认码、平时哪些只读查询会免打扰直接放行，详见 [06-安全防线与隐私边界](./06-安全防线与隐私边界.md)。

## 四、在群里想跨群查别的群记录

平时各个微信群彼此严格隔离——群友问「隔壁项目群昨天聊了啥」，AI 根本看不见别的群，也不会拿本群记录张冠李戴或瞎编充数。

但如果你本人在群里明确 `@` 机器人，比如发 `@助手 项目群昨天聊了什么`，系统核对出是你本人的微信号，就会**只在这一次回答里**临时打开「只读查档」权限，翻完历史记录答完就立刻收回。

看看同一句话，不同人在群里问的区别：

```text
普通群友在家人群问：@助手 帮我查下项目群昨天定的上线日期
→ 机器人看不见项目群，直接说明无权跨群翻查，绝不拿家人群记录凑数。

你本人在项目群问：@助手 帮我查下产品群昨天定的上线日期
→ 核对是你本人且明确 @ 了机器人，本轮临时开放只读查档，答完立刻收回。
```

为了既顺手又安全，这次临时放行守着四条硬边界：

- **只能查、不能改**：哪怕是你本人 `@` 它，在这条群回复里它也只允许翻查聊天与档案，不能跑终端命令、不能跨群发消息，也不能替别的群改便签。
- **用完立刻收回**：这条消息一答完，或者中途取消出错，临时权限都会马上撤掉，下一句对话立刻恢复普通群聊的严格隔离。
- **查完私密自动断网**：只要这一轮动用了跨群查档，本轮回答期间就会禁止访问外网链接，防止把聊天内容顺手带出去。
- **找不到群宁可直说**：如果你提到的群名在记录里对不上号，它会老实告诉你没找到，绝不会随便抓另一个群的聊天记录来糊弄你。

想了解它具体能翻哪几类历史档案、以及不同房间默认能看哪几档资料，请看 [04-性格衣柜与查资料](./04-性格衣柜与查资料.md)。
